Taxi Shift 1.0.0 test release — offline taxi missions, three unlockable cars, customization, checkpoint races, drifting, and two camera views.

- **Windows:** run `Taxi-Shift-1.0.0-Windows-Setup.exe`, or extract the complete portable ZIP and run `Taxi Shift.exe`.
- **Android:** install the APK on your phone. It opens in landscape with touch controls. The AAB is for Play Console upload, not direct installation.
- Source, build steps and installation instructions are in the repository README.

This is a prerelease for device testing. Windows binaries are unsigned by a commercial publisher. Samsung S21 testing and Play Console review remain required before production publication. Developer contact details and a hosted privacy-policy URL must be completed by the release owner. Signing credentials are deliberately excluded from all uploads.
